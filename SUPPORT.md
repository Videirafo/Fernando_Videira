# Suporte

## Onde pedir ajuda

Use **Issues** para problemas reproduzíveis, bugs, documentação incompleta ou propostas técnicas que pertençam a este repositório.

Ao abrir uma Issue, inclua quando possível:

- projeto/pasta afetada;
- sistema operacional e versão do runtime;
- passos mínimos para reproduzir;
- comportamento esperado e observado;
- logs sanitizados;
- teste ou exemplo mínimo.

## O que não publicar

Nunca publique em Issues ou Pull Requests:

- tokens, senhas, API keys ou private keys;
- arquivos `.env` reais;
- dados de clientes ou usuários;
- endpoints internos sensíveis;
- dumps de banco;
- conteúdo de repositórios privados.

Para vulnerabilidades, siga [SECURITY.md](./SECURITY.md) e evite divulgar detalhes exploráveis antes de existir uma correção.

## Escopo de suporte

Os projetos deste repositório são exemplos técnicos e labs. Eles não oferecem SLA, suporte comercial ou garantia de compatibilidade com ambientes de produção de terceiros.
