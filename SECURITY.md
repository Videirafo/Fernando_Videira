# Security Policy

Este repositório é um portfólio público e não contém credenciais, dados de clientes ou código privado de produção.

## Regras

- não publicar tokens, senhas, chaves privadas ou `.env` reais;
- não adicionar dumps de banco, logs sensíveis ou dados pessoais;
- screenshots devem ser sanitizados antes da publicação;
- cases de projetos privados devem descrever arquitetura e resultados sem revelar segredos operacionais;
- vulnerabilidades de sistemas privados não devem ser detalhadas em Issues públicas deste repositório.

## Encontrou um segredo publicado?

Não copie nem redistribua o valor. Remova-o do conteúdo público quando tiver permissão e trate a credencial como comprometida, realizando rotação/revogação no sistema de origem.

## Escopo

Esta política protege o conteúdo público deste portfólio. Cada projeto de produção deve possuir política de segurança própria, adequada ao seu domínio e infraestrutura.
