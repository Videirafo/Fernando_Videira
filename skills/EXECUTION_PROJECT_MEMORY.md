# EXECUTION & PROJECT MEMORY

## Objetivo

Manter execução focada e continuidade real entre decisões, tarefas, incidentes e entregas.

## Componentes incorporados

- Videira Focus Execution
- Project Studio Super Skill
- PM26 / PACREF
- COHI
- Second Brain Project Memory
- Harness Engineering

## Fluxo

```text
Contexto
→ objetivo atual
→ estado confirmado
→ menor próximo passo
→ execução
→ verificação
→ registro do resultado
→ próxima decisão
```

## Videira Focus Execution

- começar por ação/resultado;
- passos numerados e limitados;
- progresso explícito;
- evitar tangentes;
- erros sempre com localização, causa e correção;
- resultados verificáveis;
- um próximo passo concreto;
- confirmação antes de operação destrutiva.

## Project Studio

Para projetos maiores:

```text
Diagnóstico → escopo → arquitetura → plano → backlog → implementação
→ testes → revisão → deploy → documentação
```

## PM26 / PACREF

Usado para evitar decisões prematuras:

- problema;
- alternativas;
- contexto;
- restrições;
- riscos;
- execução;
- feedback.

## COHI

Revisão por múltiplas lentes:

1. produto e usuário;
2. arquitetura;
3. código e manutenção;
4. UX/frontend;
5. segurança/operação;
6. negócio e evolução.

## Second Brain Project Memory

Registrar apenas informação que melhora decisões futuras:

- arquitetura confirmada;
- stack;
- convenções;
- decisões e razões;
- incidentes e correções;
- endpoints/contratos públicos relevantes;
- backlog e próximos passos;
- riscos conhecidos.

Nunca registrar secrets como memória operacional.

## Harness Engineering

O projeto precisa ensinar humanos e agentes a trabalhar nele com segurança:

- README e setup reproduzível;
- contratos;
- lint/typecheck;
- testes;
- CI;
- observabilidade;
- regras de contribuição;
- instruções para agentes;
- rollback.
