# Skills & Knowledge Base

Este diretório reúne as habilidades, padrões operacionais e sistemas de engenharia consolidados durante a evolução dos projetos de Fernando Videira.

O objetivo não é colecionar nomes de ferramentas. Cada skill representa um **modo de trabalho reutilizável**, com decisões, critérios de qualidade e fluxo de execução.

## Skill mestre

### [VIDEIRA OMEGA STUDIO OS](./VIDEIRA_OMEGA_STUDIO_OS.md)

Meta-skill que conecta engenharia, produto, IA, frontend, backend, VPS, GitHub, documentação, criação visual e game development.

Pipeline mestre:

```text
RECALL → CLASSIFY → DISCOVER → GROUND → SPECIFY → DESIGN → PLAN
→ ISSUE/BRANCH → BUILD → TEST → REVIEW → SHIP → OBSERVE → LEARN → REMEMBER
```

## Princípio de uso

Uma skill não deve ser ativada só porque existe. Para cada tarefa, usar o **menor conjunto de habilidades que reduz risco e ambiguidade**.

```text
problema
  ↓
contexto real
  ↓
skills necessárias
  ↓
evidência / implementação
  ↓
testes
  ↓
resultado verificável
```

## Regra de atualização

Quando uma prática, framework ou padrão técnico ficar desatualizado:

1. verificar a fonte oficial;
2. atualizar a skill;
3. registrar a mudança;
4. não preservar comportamento antigo apenas por compatibilidade documental.
